1. JavaScript adalah bahasa pemrograman yang berjalan di sisi klien (browser) untuk membuat halaman web menjadi interaktif dan dinamis. Kegunaannya meliputi manipulasi elemen HTML dan CSS, memvalidasi input formulir pengguna, merespons aksi (seperti klik tombol), dan berkomunikasi dengan server secara asinkron (AJAX) tanpa perlu memuat ulang halaman secara keseluruhan.

2. jQuery adalah pustaka (library) open-source yang dibangun menggunakan JavaScript. Kegunaannya adalah untuk menyederhanakan penulisan kode dengan prinsip "write less, do more". jQuery mempermudah proses penjelajahan dan manipulasi Document Object Model (DOM), penanganan event, pembuatan animasi, serta implementasi AJAX, menjadikannya jauh lebih ringkas dibandingkan menulis kode JavaScript dari awal.
